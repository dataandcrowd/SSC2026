# Example rendered prompt (template `cl-v1`)

Generated by `scripts/make_example_prompt.py` from `runs/L-clock_mock_py_s1`, agent 6, day 11 (triggers: T2). The user message is copied verbatim from `llm_calls.jsonl`; no API call was made. The run used the MockLLM backend, so the answer at the end is the deterministic stand-in, not a model reply.

Neither the archetype nor the trait names nor the generalised cost (GC) appear in the prompt. Work and study are described by the same constraint sentences, and start-time flexibility is graded in four steps that follow the rule's schedule-delay multiplier. This commuter's employer allows the earlier working day, so the situation states it and the `start time` column shows which start each option is measured against.

Prompt size: 5112 characters, about 1278 tokens (approximate: characters / 4; excludes the schema and the output). Count it as uncached input: the system prompt is below the minimum cacheable prefix and the schema differs per agent.

## System prompt

```text
You simulate the morning travel decision of one commuter who travels into Auckland city centre on a weekday. You are given this person's circumstances, how they tend to decide, their recent trips, today's information and the options open to them today.
Decide as this person would, weighing their own circumstances, tendencies and recent experience. Use only the information given. Do not rely on demographic or occupational stereotypes.
Choose exactly one option id from the options table. Give the person's reason in the first person, in at most 30 words, and list the factors that mattered most.
```
